### 费用说明

**Cloudflare（免费）**：
- Pages：静态文件托管，全球 CDN 加速
- Functions：每天 10 万次免费调用，足够个人使用
- 自定义域名：支持绑定自己的域名

**OpenRouter API（按需）**：
- 免费额度：新用户赠送约 5-10 元额度
- 计费方式：按 token 计费，约 0.01-0.05 元/千 token
- 预估：每天调用 10 次，每月约 5-20 元

## 三、成本优化建议

### 1. 当前成本最高的项目

| 项目 | 费用 | 占比 |
|------|------|------|
| OpenRouter AI 调用 | 5-50元/月 | 100% |
| 其他服务 | 0元 | 0% |
(实则使用免费模型)

### 2. 优化方案

**方案 A：使用免费 AI 模型**
```
模型选择：
- arcee-ai/trinity-large-preview:free （免费）
- openai/gpt-3.5-turbo-instruct:free （免费额度）
- mistralai/mistral-7b-instruct:free （免费）

效果：完全免费，但响应速度和质量可能略差
```

**方案 B：限制每日调用次数**
```
在代码中添加调用次数限制：
- 本地存储调用记录
- 每天限制 5-10 次调用
- 超出后提示用户明天再用

预估费用：约 5-10元/月
```

**方案 C：让用户自己配置 API Key**
```
在设置页面让用户输入自己的 OpenRouter API Key
- 开发者不承担费用
- 用户用自己的额度
- 完全免费运行
```

**方案 D：部署到本地**
```
不部署到云端，只在本地运行：
- 用 Python 启动本地服务器
- 不分享给他人使用
- 完全免费（只消耗个人 API 额度）
```

### 3. 推荐方案

| 用户类型 | 推荐方案 | 费用 |
|---------|---------|------|
| 个人学习 | 方案 A（免费模型） | 0元 |
| 日常使用 | 方案 B（限制调用） | 5-10元/月 |
| 分享给他人 | 方案 C（用户配置） | 0元 |
| 仅本地测试 | 方案 D（本地运行） | 0元 |

### 4. 优化后的预计成本

| 优化方案 | 优化前 | 优化后 | 节省 |
|---------|--------|--------|------|
| 使用免费模型 | 20元/月 | 0元 | 100% |
| 限制调用次数 | 20元/月 | 5元/月 | 75% |
| 用户自配 Key | 20元/月 | 0元 | 100% |
