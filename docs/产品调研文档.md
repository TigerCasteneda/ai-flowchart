# 产品调研文档

## 一、调研产品基本信息

### 1. 产品名称
Next AI Draw.io（AI 智能图表绘制工具）

### 2. 产品用途
通过自然语言描述，由 AI 自动生成各种类型的图表（流程图、思维导图、架构图、示意图等），无需手动拖拽绘制，大幅提高文档编写和设计效率。

### 3. 日常使用场景
- **技术文档编写**：描述系统架构，自动生成架构图
- **会议记录整理**：将讨论内容转化为清晰的流程图或思维导图
- **学习笔记**：将知识点整理为可视化图表，便于理解和记忆
- **项目规划**：描述项目流程，自动生成甘特图或任务流程图
- **教学演示**：将复杂概念（如光合作用、水循环）转化为直观示意图

### 4. 核心功能清单

| 序号 | 功能名称 | 功能描述 |
|------|---------|----------|
| 1 | 自然语言绘图 | 用中文/英文描述想要的图表，AI 自动生成 |
| 2 | 文档转图表 | 上传文档（.txt/.md/.docx），AI 分析内容自动生成图表 |
| 3 | 多种图表类型 | 支持流程图、思维导图、架构图、示意图等 |
| 4 | 手动编辑 | 支持拖拽节点、连线、调整样式 |
| 5 | 形状工具 | 提供矩形、圆形、菱形、箭头等基础图形 |
| 6 | 导出功能 | 支持导出 PNG 图片和 JSON 数据 |
| 7 | 撤销/重做 | 支持操作历史回退 |
| 8 | 画布缩放 | 支持放大、缩小、平移画布 |

## 二、核心功能技术逻辑拆解

### 1. 自然语言绘图功能

**实现原理：**
```
用户输入文字描述
    ↓
发送给 AI 大模型（如 GPT、Claude）
    ↓
AI 理解意图，输出结构化数据（JSON/XML）
    ↓
前端解析数据，绘制到画布
```

用通俗语言解释：
- 就像"翻译"一样，AI 把你的文字翻译成电脑能懂的图表格式
- 例如你说"画一个用户登录流程图"，AI 就生成包含"开始→输入账号→验证→成功/失败"的数据
- 前端收到数据后，像"搭积木"一样把节点和连线画出来

### 2. 文档转图表功能

**实现原理：**
```
用户上传文档文件
    ↓
程序读取文件内容（文字）
    ↓
将内容发送给 AI
    ↓
AI 分析文档结构，提取关键信息和逻辑关系
    ↓
AI 生成对应的图表数据
    ↓
前端渲染图表
```

### 3. 画布绘图功能

**核心组件：**
- **Canvas 画布**：HTML5 提供的绘图区域，像一张电子白纸
- **节点数据**：记录每个图形的位置、大小、颜色、文字
- **连线数据**：记录节点之间的连接关系和箭头方向
- **渲染引擎**：负责将数据画到画布上

### 4. 产品界面与交互

| 区域 | 组件 | 功能 |
|-----|------|------|
| 左侧边栏 | AI 输入框 | 输入文字描述，点击发送生成图表 |
| 左侧边栏 | 形状工具 | 手动添加各种图形 |
| 左侧边栏 | 样式面板 | 调整颜色、边框、文字大小 |
| 中间 | 画布主区域 | 显示和编辑图表 |
| 顶部 | 工具栏 | 撤销、重做、清空、导出按钮 |
| 右侧 | 属性面板 | 修改选中节点的属性 |

## 三、同类产品对比

### 对比产品

| 对比维度 | Next AI Draw.io | Draw.io (原版) | Mermaid |
|---------|----------------|----------------|---------|
| AI 绘图 | ✅ 支持 | ❌ 不支持 | ❌ 不支持 |
| 自然语言输入 | ✅ 支持 | ❌ 不支持 | ❌ 不支持 |
| 文档转图表 | ✅ 支持 | ❌ 不支持 | ❌ 不支持 |
| 手动绘图 | ✅ 支持 | ✅ 支持 | ❌ 代码方式 |
| 使用门槛 | 极低 | 中等 | 需要学习语法 |
| 开源免费 | ✅ 是 | ✅ 是 | ✅ 是 |

### 优势与不足

**优势：**
1. **革命性交互**：不用学习，说句话就能画图
2. **提高效率**：比手动拖拽快 10 倍以上
3. **降低门槛**：新手也能画出专业图表

**不足：**
1. **依赖 AI**：没有 AI 就用不了核心功能
2. **需要 API Key**：AI 调用需要付费或有免费额度
3. **AI 可能出错**：复杂图表可能需要多次调整

## 四、调研总结：复刻方向确定

### 1. 本次复刻将保留的核心功能

| 优先级 | 功能 | 理由 |
|--------|------|------|
| ⭐⭐⭐ 核心 | 自然语言生成图表 | 最核心的创新功能 |
| ⭐⭐⭐ 核心 | 文档转图表 | 差异化竞争点 |
| ⭐⭐ 重要 | 基础形状绘制 | 矩形、圆形、菱形、箭头 |
| ⭐⭐ 重要 | 节点拖拽和连线 | 基本编辑能力 |
| ⭐ 可选 | 导出 PNG/JSON | 保存和分享成果 |

### 2. 复刻将简化或舍弃的功能

| 功能 | 状态 | 理由 |
|------|------|------|
| 复杂图形库 | 简化 | 只保留常用形状，降低复杂度 |
| 实时协作 | 舍弃 | 单人使用为主，不需要多人编辑 |
| 云端存储 | 舍弃 | 本地导出即可，减少开发量 |
| 图表模板 | 简化 | AI 生成本身就是模板 |

### 3. 复刻的核心目标

> **实现一款"基于 AI 的简易智能图表工具"，用户输入文字描述，就能自动生成清晰的流程图或示意图，支持基础的拖拽编辑功能。**
